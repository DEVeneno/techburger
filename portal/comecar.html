Começar: o seu card no time

Todo dev da AprendendoDev tem um card na pasta equipe/. É o seu primeiro pull request: depois do merge, você aparece na página Time e o robô já sabe qual é o seu squad.

  1. 1. Ter uma conta no GitHub

    Já tem? Entre nela. Não tem? Crie com o seu e-mail e escolha um usuário simples (ex.: maria-silva).

    Entrar no GitHub Criar conta
  2. 2. Preencher o card

      Como o seu card vai ficar:

      
      
      • 
      
    • 
        3. Enviar para o GitHub
        
      
        
        
          
      1. Antes de tudo, confirme o seu e-mail no GitHub (link no e-mail de boas-vindas ou em Settings › Emails). Sem isso o GitHub não deixa criar o fork e o botão não faz nada.
        2. 
          
      2. Clique em 1. Criar o meu fork e depois em Create fork. Só precisa fazer uma vez (se disser que o fork já existe, tudo certo).
        3. 
          
      3. Volte aqui e clique em 2. Criar o meu card no GitHub: abre o arquivo já preenchido. Se ainda aparecer Fork this repository e nada acontecer, recarregue a página (F5).
        4. 
          
      4. Confira o nome do arquivo e o texto (se a caixa vier vazia, digite o nome e cole com Ctrl+V). Clique em Commit changes..., escreva a mensagem Adiciona card de @seu-usuario e clique em Propose changes.
        5. 
          
      5. Na tela Comparing changes (1 arquivo novo), clique em Create pull request duas vezes.
        6. 
          
      6. No campo Issue do modelo, escreva Parte de #1. Se esquecer, o robô do time coloca para você.
        7. 
        
      
      
      • 
      
    • 
        4. Aguardar o merge
        
      O professor revisa e faz o merge. Acompanhe na página Sprint › Minha tarefa: quando o card entrar, o passo fica verde e você já pode pegar uma tarefa.
