Começar: o seu card no time

Todo dev da AprendendoDev tem um card na pasta equipe/. É o seu primeiro pull request: depois do merge, você aparece na página Time e o robô já sabe qual é o seu squad.

  1. 1. Ter uma conta no GitHub

    Já tem? Entre nela. Não tem? Crie com o seu e-mail e escolha um usuário simples (ex.: maria-silva).

    Entrar no GitHub Criar conta
  2. 2. Preencher o card

      Como o seu card vai ficar:

      
      
      • 
      
    • 
        3. Enviar para o GitHub
        
      
        
        
          
      1. O botão abre o GitHub com o arquivo já preenchido. Se aparecer Fork this repository, clique nele.
        2. 
          
      2. Confira o nome do arquivo e o texto. Clique em Commit changes..., deixe a mensagem Create seu-usuario.md e clique em Propose changes.
        3. 
          
      3. Na tela Comparing changes (1 arquivo novo), clique em Create pull request duas vezes.
        4. 
          
      4. No campo Issue do modelo, escreva Parte de #1. Se esquecer, o robô do time coloca para você.
        5. 
        
      
      
      • 
      
    • 
        4. Aguardar o merge
        
      O professor revisa e faz o merge. Acompanhe na página Sprint › Minha tarefa: quando o card entrar, o passo fica verde e você já pode pegar uma tarefa.
