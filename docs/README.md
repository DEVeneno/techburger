# A modelagem do TechBurger

Tudo o que o app vai fazer é decidido aqui, antes de virar código (Sprints 1 a 3) — e consultado o tempo todo depois.

| Arquivo / pasta | O que tem | Sprint |
|-----------------|-----------|--------|
| [`requisitos.md`](requisitos.md) | Regras de negócio, requisitos funcionais e não funcionais | 1 |
| `diagramas/canvas.drawio` | Business Model Canvas do TechBurger | 1 |
| `diagramas/<squad>/` | Casos de uso, classes, atividades, sequência e wireframes de cada módulo | 2 a 4 |

## Como entregar um diagrama

1. Desenhe no [draw.io](https://app.diagrams.net) e salve como **`.drawio`** no seu computador.
2. No **seu fork**, abra a pasta `docs/diagramas/<seu-squad>/` e clique em **Add file › Upload files**.
3. Arraste o arquivo, escreva a mensagem do commit (ex.: `Cria casos de uso do carrinho`) e escolha **Create a new branch**.
4. Abra o pull request com `Closes #número-da-issue`.

Nome dos arquivos: sem espaço e sem acento — `casos-de-uso.drawio`, `classes.drawio`, `atividades-finalizar-pedido.drawio`.
